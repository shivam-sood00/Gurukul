# Go2+D1 APEX Motion Data Provenance

The Gurukul project maintainer confirms that the motion data in these two directories was created for this project:

- `imitation_data/go2_d1_motions_csv/`
- `npz/go2_d1/`

The CSV files are repository-authored Go2+D1 demonstrations. The NPZ files are converted, composed, or additional
repository-authored Go2+D1 trajectories used by the local APEX tracking and manipulation tasks. Local conversion and
editing tools, including EmbodiK where documented on the public Motion Data page, were used to produce the robot
trajectories.

These files are released under Gurukul's root Apache-2.0 license. This statement applies only to the two directories
listed above. It does not cover sibling motion collections such as `animal_mocap`, `cross_morpho`,
`corss_morpho_new`, `learn_diverse_quad_loco`, or `walk_these_ways`, whose source-data terms must be handled
separately.
