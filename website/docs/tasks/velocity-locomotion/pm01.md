# EngineAI PM01 Velocity

PM01 flat and rough velocity locomotion use the retained official 24-DoF USD with EngineAI's authored black, silver,
white, and orange/red materials. Every revolute joint is controlled, including `J23_HEAD_YAW`. The actuator gains,
armatures, effort and velocity limits, and action scales are shared with the official EngineAI BeyondMimic
configuration.

## Train

Train flat locomotion:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-Velocity-Flat-EngineAI-PM01-v0 \
  --num_envs 16384 \
  --logger wandb \
  --headless \
  --run_name engineai_pm01_official_urdf_flat_ppo
```

Train rough-terrain locomotion:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-Velocity-Rough-EngineAI-PM01-v0 \
  --num_envs 16384 \
  --logger wandb \
  --headless \
  --run_name engineai_pm01_official_urdf_rough_ppo
```

Runs are written under `logs/rsl_rl/engineai_pm01_official_urdf_flat/` and
`logs/rsl_rl/engineai_pm01_official_urdf_rough/`.

## MuJoCo Sim2Sim

The velocity actor has 1,173 observations and 24 actions. Five actor terms have 15-frame histories; the current
3-D velocity command is inserted between projected gravity and joint position. Both training and deployment run the
low-level simulation at 500 Hz and the policy at 50 Hz. The training critic has 1,218 observations, including a
15-frame history of the privileged base linear velocity.

After exporting a trained ONNX policy, run it against EngineAI's official native-SDK MuJoCo scene:

```bash
python engineai-sim2real/RL_policy_runner/sim2sim/run_pm01_policy.py \
  --policy-path logs/rsl_rl/engineai_pm01_official_urdf_flat/<run>/exported/policy.onnx \
  --launch-mujoco \
  --mujoco-viewer native
```
