# Manipulation

Manipulation tasks define an object-interaction goal, from moving a mobile base and arm together to reorienting an
object in one hand.

| Task family | Use it for |
| --- | --- |
| [Loco-Manipulation](loco-manipulation) | Combine locomotion with reaching, grasping, pushing, throwing, or other whole-body object interaction. |
| [Quadruped + Arm](quadruped-with-arm) | Select Go2+Airbot, Go2+D1, or B2+Z1 task and controller guides. |
| [EngineAI PM01 Loco-Manipulation](beyondmimic/pm01#loco-manipulation) | Train PM01 tabletop sliding or heavy-crate pushing with DeepMimic or AMP. |
| [Revo3 Dexterous Hand](revo3-dexhand) | Train in-hand cube/cylinder tasks or the Tianji+Revo3 lift task. |

Language-conditioned selection of robot primitives is organized separately under
[Planning & Autonomy](planning-autonomy), even when its first adapter uses a mobile manipulator.
