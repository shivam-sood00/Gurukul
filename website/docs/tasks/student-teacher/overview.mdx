## Typical pattern

1. Train or select a teacher run.
2. Train a student with the matching task and distillation/action-prior agent entry point.
3. Use explicit teacher checkpoint flags when the student and teacher run folders differ.
4. Play the student checkpoint and check observations, action order, and export behavior.
5. Export only deployable student actors to sim2sim; teacher-side privileged observations stay in Isaac Lab evaluation.

## Example flags

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=<student_task_id> \
  --headless \
  --agent=<student_agent_entry_point> \
  --teacher_load_run <teacher_run_folder_name> \
  --run_name <student_run_name>
```

Use the linked student-teacher subpages for exact task IDs and agent entry points.

For concurrent teacher-student training, use the dedicated [Concurrent Teacher-Student](concurrent-teacher-student) page.
