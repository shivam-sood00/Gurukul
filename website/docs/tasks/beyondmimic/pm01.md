# EngineAI PM01 BeyondMimic

The PM01 BeyondMimic tasks use EngineAI's official 24-DoF asset and policy contract:

| Surface | Training evidence | Artifact | Transfer |
| --- | --- | --- | --- |
| Tracking and experimental object-task registrations | Static contract/unit tests; no local convergence result | Official dance artifact only; walking/object-task policies are not bundled | Dance/walking MuJoCo adapter; object tasks have no transfer runner |

See the [exact task-stage catalog](../../reference/task-status) before selecting an artifact or transfer path.

:::caution[Local motion files required]
Generated or copied NPZ motion archives are not distributed. Obtain permitted PM01 source motions from the
[official EngineAI RL Lab](https://github.com/engineai-robotics/engineai_rl_lab) and install them at:

```text
source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_pm01_24dof/motion/
```

The commands below expect `dance.npz` and, for walking or heavy-push variants, `walking_24dof.npz`. These local NPZ
files are ignored by Git. The checked-in EngineAI code, robot assets, policy artifacts, and notices retain their
upstream BSD-3-Clause terms.
:::

## Play EngineAI's Official 24-Action Dance Policy

```bash
python scripts/reinforcement_learning/rsl_rl/play.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-PM01-24DoF-Wo-State-Estimation-v0 \
  --checkpoint source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_pm01_24dof/pretrained/dance.pt \
  --num_envs 1
```

Replay its reference motion without policy inference:

```bash
python scripts/tools/beyondmimic/replay_npz.py \
  --robot pm01-24dof \
  --file source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_pm01_24dof/motion/dance.npz
```

## MuJoCo Sim2Sim

The repository includes EngineAI's official PM01 MuJoCo model and the official 129-observation/24-action ONNX:

```bash
MUJOCO_GL=disable python \
  engineai-sim2real/RL_policy_runner/sim2sim/run_pm01_beyondmimic_policy.py
```

Omit `MUJOCO_GL=disable` and add `--viewer --real-time` for viewed playback:

```bash
python engineai-sim2real/RL_policy_runner/sim2sim/run_pm01_beyondmimic_policy.py \
  --viewer \
  --real-time
```

Train the official 24-action contract with:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-PM01-24DoF-Wo-State-Estimation-v0 \
  --num_envs 4096 \
  --headless
```

Train the 24-action walking tracker:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-PM01-24DoF-Walking-Wo-State-Estimation-v0 \
  --num_envs 4096 \
  --headless
```

Play a trained walking checkpoint:

```bash
python scripts/reinforcement_learning/rsl_rl/play.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-PM01-24DoF-Walking-Wo-State-Estimation-v0 \
```

```bash
  --motion source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_pm01_24dof/motion/walking_24dof.npz
```

## Loco-Manipulation

The tabletop scene contains a fixed 0.9 x 0.75 m table and a 0.3 kg nominal cuboid whose scale, mass, friction,
initial position, and yaw are randomized. The objective is to slide it to a fixed goal using the two terminal arm
links while keeping the PM01 motion style. The heavy scene replaces the table with a 0.45 x 0.50 x 0.42 m crate,
randomized over 6--10 kg, and rewards standoff approach, bilateral arm-end proximity, goal-directed object velocity,
uprightness, and final planar position.

The checked-in walking archive travels several meters in its source world frame. Heavy-push configs convert its
horizontal anchor trajectory to an in-place reference at load time while retaining joint motion, vertical motion, and
relative body kinematics. This preserves reference-state diversity without spawning a randomized walking phase several
meters away from the crate; the reduced global-anchor reward then allows task-driven forward progress.

Authenticate once with `wandb login` before using the W&B-enabled commands below.

Train the DeepMimic-style variants with RSL-RL:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-LocoManip-Tabletop-EngineAI-PM01-DeepMimic-v0 \
  --num_envs 4096 \
  --logger wandb \
  --wandb_project_name Gurukul-EngineAI-PM01-LocoManip \
  --headless
```

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-LocoManip-HeavyPush-EngineAI-PM01-DeepMimic-v0 \
  --num_envs 4096 \
  --logger wandb \
  --wandb_project_name Gurukul-EngineAI-PM01-LocoManip \
  --headless
```

```bash
python scripts/reinforcement_learning/skrl/train.py \
  --task=Gurukul-Isaac-LocoManip-Tabletop-EngineAI-PM01-AMP-v0 \
  --algorithm AMP \
  --num_envs 4096 \
  --logger wandb \
  --wandb_project_name Gurukul-EngineAI-PM01-LocoManip \
  --headless
```

```bash
python scripts/reinforcement_learning/skrl/train.py \
  --task=Gurukul-Isaac-LocoManip-HeavyPush-EngineAI-PM01-AMP-v0 \
  --algorithm AMP \
  --num_envs 4096 \
  --logger wandb \
  --wandb_project_name Gurukul-EngineAI-PM01-LocoManip \
  --headless
```

The DeepMimic tasks retain reference-state initialization, phase-conditioned reference observations, explicit
whole-body tracking rewards, and early termination, then add task rewards. The AMP tasks retain reference-state
initialization but remove the phase and explicit tracking terms. Their discriminator sees two consecutive states made
from joint position/velocity, root height/orientation/linear and angular velocity, and root-relative tracked-body
positions. Object and goal features stay in the task policy only, so the learned prior remains task-agnostic. The AMP
trainer uses equal task/style weights, a motion dataset, a policy replay buffer, and a reference-data gradient penalty.

These choices follow [DeepMimic](https://arxiv.org/abs/1804.02717) and its
[official implementation](https://github.com/xbpeng/DeepMimic),
[AMP](https://arxiv.org/abs/2104.02180) and the authors' maintained
[ASE/AMP reference implementation](https://github.com/nv-tlabs/ASE), and the compatible randomization and shaping
ideas from [Sim-to-Real Learning for Humanoid Box Loco-Manipulation](https://arxiv.org/abs/2310.03191). The PM01
motion files contain walking and dance, not object-interaction demonstrations, so AMP regularizes whole-body motion
style rather than imitating manipulation contacts.
