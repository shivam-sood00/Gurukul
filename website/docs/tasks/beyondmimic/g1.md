# Unitree G1 BeyondMimic

The G1 tasks use the shared BeyondMimic rewards and motion command with the 29-DoF G1 asset. The APEX tracker variant
adds current and future reference observations at frame offsets `0, 1, 2, 5, 10`.

## Task IDs

| Task ID | Purpose |
| --- | --- |
| `Gurukul-Isaac-BeyondMimic-Flat-Unitree-G1-v0` | Base BeyondMimic reference-motion PPO task. |
| `Gurukul-Isaac-BeyondMimic-APEX-Flat-Unitree-G1-v0` | BeyondMimic task with APEX-style future reference observations. |
| `Gurukul-Isaac-G1-APEX-Flat-Tracker-v0` | Short alias for the same APEX-style G1 tracker config. |

## Prepare the Motion

The public repository excludes the inherited G1 CSV and NPZ motion clips. Obtain a permitted G1 motion independently,
place it in the ignored local directory below, and generate the NPZ expected by the config:

```text
source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/g1/motion/
```

One known source is the
[Unitree-retargeted LAFAN1 dataset](https://huggingface.co/datasets/lvhaidong/LAFAN1_Retargeting_Dataset). Its dataset
page identifies CC BY-NC-ND terms for the underlying motion data, so confirm that your use and derived-file handling
are permitted before downloading it. For the original development filename, the conversion command is:

```bash
python scripts/tools/beyondmimic/csv_to_npz.py \
  --input_file source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/g1/motion/G1_Take_102.bvh_60hz.csv \
  --input_fps 60 \
  --output_fps 50 \
  --headless
```

## Train

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-Unitree-G1-v0 \
  --headless
```

For future-reference observations, train the tracker alias instead:

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-G1-APEX-Flat-Tracker-v0 \
  --headless
```

## Play

```bash
python scripts/reinforcement_learning/rsl_rl/play.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-Unitree-G1-v0 \
  --load_run <run_folder_name> \
  --num_envs 1
```

## Credits

The task is informed by [BeyondMimic](https://arxiv.org/abs/2508.08241); the future-reference variant also uses the
local [APEX](https://arxiv.org/abs/2511.09091)-style observation interface. This is reference-motion PPO, not the
BeyondMimic paper's guided-diffusion controller.
