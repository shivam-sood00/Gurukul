# EngineAI T800 BeyondMimic

The T800 task includes EngineAI's 25-DoF robot asset, trained RSL-RL checkpoint, and ONNX/MNN exports, and supports its
50 Hz dance motion when that motion is installed locally. It also provides a policy-contract runner against EngineAI's
official MuJoCo model, so the full motion can be checked before native-SDK or robot deployment.

:::caution[Local motion file required]
The generated or copied `dance_t800.npz` archive is not distributed. Obtain the permitted source motion from the
[official EngineAI RL Lab](https://github.com/engineai-robotics/engineai_rl_lab) and place it in the ignored local
directory:

```text
source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_t800/motion/
```

The checked-in EngineAI code, robot asset, policy artifacts, and notices retain their upstream BSD-3-Clause terms.
:::

## Play the Trained Policy

Use the no-state-estimation task for the imported `dance.pt` checkpoint:

```bash
python scripts/reinforcement_learning/rsl_rl/play.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-T800-Wo-State-Estimation-v0 \
  --checkpoint source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_t800/pretrained/dance.pt \
  --num_envs 1
```

Replay the reference motion without the policy:

```bash
python scripts/tools/beyondmimic/replay_npz.py \
  --robot t800 \
  --file source/Gurukul/Gurukul/tasks/manager_based/beyondmimic/config/engineai_t800/motion/dance_t800.npz
```

## Train

```bash
python scripts/reinforcement_learning/rsl_rl/train.py \
  --task=Gurukul-Isaac-BeyondMimic-Flat-EngineAI-T800-Wo-State-Estimation-v0 \
  --num_envs 4096 \
  --headless
```

## MuJoCo Sim2Sim

The official MuJoCo XML and meshes remain in EngineAI's native SDK. Clone it next to this repository or point the
runner at an existing checkout:

```bash
git clone https://github.com/engineai-robotics/engineai_robotics_native_sdk.git

python engineai-sim2real/RL_policy_runner/sim2sim/run_t800_beyondmimic_policy.py \
  --native-sdk-root ../engineai_robotics_native_sdk
```

The headless runner checks the exact exported interface: a 134-value actor observation, 25 actions, 50 Hz policy
control, 500 Hz MuJoCo stepping, EngineAI's joint ordering, PD gains, reference-yaw alignment, and native-SDK action
scales. Add `--viewer --real-time` for interactive playback.

To test the RL export's elbow-yaw scales instead of the native SDK's safer values:

```bash
python engineai-sim2real/RL_policy_runner/sim2sim/run_t800_beyondmimic_policy.py \
  --native-sdk-root ../engineai_robotics_native_sdk \
  --action-scale-source export
```

## Official Native-SDK Flow

EngineAI's full C++ state-machine route uses MNN, LCM, a virtual gamepad, PD stand, and automatic dance-to-walk
transition. In EngineAI's documented container:

```bash
# Terminal 1
./scripts/run_mujoco.sh t800

# Terminal 2
./run.sh t800

# Terminal 3
python3 tools/virtual_gamepad/virtual_gamepad.py
```

Enter PD stand and reset the MuJoCo robot before entering dance mode. Do not proceed to hardware until the native
simulator, state transitions, joint ordering, gains, limits, remote stop, and elbow-yaw scale choice have all been
verified.

The task follows the reference-motion objective described by [BeyondMimic](https://arxiv.org/abs/2508.08241), while
the robot assets and policy artifacts are the pinned EngineAI sources credited above.
